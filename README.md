# Zhenhao Liu — Personal website

An academic profile for Zhenhao Liu, a PhD student in the Lampe Joint Department of Biomedical Engineering at UNC–Chapel Hill and NC State.

The site uses Carolina blue (#4B9CD3), deep navy (#13294B), and Georgia typography throughout. It includes a short biography, research interests, master's and bachelor's education, a portrait, and links to LinkedIn, Google Scholar, and the lab website. The layout adapts to desktop and mobile screens.

## Files

- index.html: page content and styling.
- assets/zhenhao-liu-portrait.png: the portrait used on the page.

Open index.html in a browser to preview it locally. Keep the assets folder beside the HTML file. No build tools or installation are required.

## GitHub Pages

In this repository's Settings → Pages, set Source to Deploy from a branch, select main and / (root), then Save.

The site address will be https://17zhenhowe.github.io/ once GitHub finishes publishing. Future updates to the main branch will update the site automatically.
